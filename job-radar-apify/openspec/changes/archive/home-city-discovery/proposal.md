# Enlaces de ciudades piloto desde el inicio

Entrega de implementación derivada del baseline del PR #64. El HTML inicial
de / y /ve carece de enlaces a categorías; React ya muestra tarjetas de algunas
ciudades, pero Cúcuta no está entre las seis tarjetas CO. Incorporar un bloque
pequeño de destinos existentes compartido por HTML, Markdown y cliente.

Piloto: Bogotá/Cúcuta en CO y Caracas en VE. No nuevas rutas, queries,
estadísticas, títulos, canonicals, filtros ni solicitudes de indexación.
Objetivo verificable: enlaces útiles disponibles sin JS y conservados después
de montarlo, aunque home-stats falle. No se promete ranking ni indexación.
